# STScI Transients Website

An original, responsive static website for the STScI Transient Science Research Group. It adapts the content architecture of the group's Google Site into a polished single-page experience inspired by the section-based navigation of HTML5 UP's Hyperspace template.

## What is included

- `index.html` — semantic page content and sections
- `styles.css` — responsive layout, visual system, and CSS artwork
- `script.js` — mobile navigation, section tracking, and subtle reveal effects

## Local preview

Open `index.html` in a browser, or use a local web server such as:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The site has no build step or runtime dependencies.
